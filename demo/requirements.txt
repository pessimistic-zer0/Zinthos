#
# `spaces` is here although nothing wants a GPU. A free account can only run a Gradio Space on
# ZeroGPU hardware, and that runtime expects the package imported at startup — without it the
# Space was killed ~45 s into every cold start, while the app was alive, bound and answering
# 200 on every probe. No @spaces.GPU function is ever called, so no GPU is allocated and no
# subprocess is forked.
